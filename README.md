# The Quiet Room

Витрина бренда принтов «The Quiet Room» (Тихая Комната) — метафора домашнего уюта, в котором висят ваши работы.

Сайт: https://eugene55555.github.io/the-quiet-room/

## Что здесь

- `index.html` — одностраничная витрина (hero, коллекция, о бренде, как купить)
- `assets/style.css` — токены бренда: крем #F7F2EA, графит #2E2A26, медь #B47C4F, золото #A98A4B, шалфей #7C8B72
- `assets/logo.svg` — логотип: корона + каллиграфическая надпись (Great Vibes, Google Fonts)

## Как обновлять

Правки в `index.html` / `assets/` → `git push` — GitHub Pages подхватывает автоматически (ветка `main`, папка `/`).

Магазин пока не подключён: кнопки покупки появятся, когда будет готов Etsy-магазин (или другой канал).
