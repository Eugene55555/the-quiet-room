🦋 Адмінка витрини «The Quiet Room»

Редагуєш — копіюєш JSON — вставляєш у файл config.json на GitHub — сайт оновлюється. Без коду.

Товари (принти)

Кожен принт — це картка на витрині. Назва, опис, ціна (₴), картинка, посилання на BlackSea. Щоб сховати товар — зніми галочку «показувати».

Кольори

Чотири головні кольори бренду. Вино — основний, глибоке вино — для футера, крем — фон, золото — акценти.

Шрифти

Готові пари шрифтів: плакатний заголовок + текстовий. Обидві підтримують українську.

Бренд і логотип

Назва бренду з'являється в шапці, в меню і в футері. Логотип: порожньо = каліграфічний знак за замовчуванням; вкажи шлях до свого SVG (наприклад assets/logo.svg або assets/logo2.svg) — і він замінить знак. Сам SVG можна завантажити на GitHub як файл.

Соціальні мережі

Встав повні посилання (https://...). Порожнє поле = іконки не буде. Іконки з'являться в футері і в мобільному меню.

Промо-смуга вгорі

Текст, який бачить кожен відвідувач у жовтій смузі над шапкою. Окремо українською та англійською. Порожньо — смуга зникне.

Як викласти зміни на сайт (1 раз — 2 хвилини)

  1. Натисни «Скопіювати config.json» внизу.
  2. Відкрий github.com/Eugene55555/the-quiet-room → файл config.json → кнопка ✏️ Edit (олівець).
  3. Виділи все старе (Ctrl+A) і встав нове (Ctrl+V).
  4. Натисни Commit changes → Commit changes ще раз.
  5. Зачекай 1–2 хвилини і відкрий сайт — потягни стрічку вниз (оновлення). Готово!

Підказка: щоб додати нову картинку принта — завантаж її в ту саму папку assets/img/ (Add file → Upload files) і вкажи шлях assets/img/ім'я.svg у товарі.
