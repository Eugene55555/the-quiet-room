🦋 Адмінка «The Quiet Room»

Все робиться мишкою — без коду. Наприкінці: «Скачати файл» → надіслати мені в чат.

Принти (товари)

Кожен блок — один принт на витрині. «＋ Додати принт» — і заповнюй. Картинку завантаж з телефону або комп'ютера кнопкою «📷 Картинка» — вона збережеться прямо у файлі.

Палітра сайту

Обери готову схему одним натисканням — або налаштуй кожен колір вручну нижче.

Шрифти

Три готові стилі, всі підтримують українську.

Соціальні мережі

Можна просто @нік — доповнимо самі. Порожнє поле = іконки не буде.

Промо-смуга (верх сайту)

Золота смуга над шапкою. Порожньо — смуги не буде.

Назва бренду і логотип

Логотип не обов'язковий: порожньо = каліграфічний знак. Завантаж свій SVG або PNG — і він замінить знак.

Залити зміни на сайт — без коду і без GitHub

GitHub тобі не потрібен. Три кроки:

1️⃣ Натисни «💾 Скачати файл» нижче — завантажиться маленький файлик config.json.
2️⃣ У цей чат зі мною відправ цей файл — як звичайне фото.
3️⃣ Я за хвилину заллю його на сайт і відпишусь. Готово! ✅

Немає можливості скачати? Натисни «📋 Скопіювати» і встав текст мені одним повідомленням.

Дії з файлом

Файл — це весь твій магазин: товари, кольори, шрифти, соцмережі. Він маленький, навіть з картинками.


    

    

      
Корисне

      
«💾 Чернетка» вгорі — зберегти все на цьому пристрої і продовжити пізніше. Порядок принтів міняється кнопками ▲▼. Новий принт без картинки отримає мокап-футболку.

✨ Хочеш публікувати в один клік без файлів? Відкрий вкладку «🎨 Sanity» — хмарна студія вже підключена.

    

  


  
  

    

      
🎨 Sanity Studio — принти та налаштування сайту

      
Сайт уже читає Sanity: опублікував принт у студії — він зʼявився на витрині. Миттєво, без файлів і без GitHub.

      

        Як додати новий принт (1 хвилина):

        1️⃣ Відкрий студію: https://quiet-room.sanity.studio → увійди своїм акаунтом Sanity (тим, яким створював проект).

        2️⃣ Ліворуч обери Принт → Create new → заповни: назва укр/англ, опис, ціна, посилання покупки (BlackSea), картинка.

        3️⃣ Натисни Publish — все, принт уже на сайті. Порядок — полем «Порядок», сховати — «Показувати на витрині».

        4️⃣ Розділ Налаштування сайту (siteSettings) — бренд, кольори, шрифт, соцмережі, промо-смуга. (Після зміни кольорів/шрифтів теж натисни Publish.)
      

      
Назва проєкту в Sanity зараз «pod» — у manage.sanity.io (Project Settings) її можна перейменувати на «The Quiet Room», на роботу це не впливає.

      
Поля нижче зберігаються тільки у твоєму браузері (localStorage) і нікуди не надсилаються.
